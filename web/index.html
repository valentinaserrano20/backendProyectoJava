Defensa Civil Colombiana

El entorno de base de datos y servicios API en Java se ha conectado con éxito. El servidor está listo para recibir y procesar solicitudes del cliente.

Para ingresar al sistema:

Abre una terminal en la carpeta del proyecto y ejecuta el servidor de desarrollo del frontend:
$cd UIProyectoJava $npm run dev
Luego accede a la dirección local que te indique Vite (normalmente http://localhost:5173).
